# Language Policy

OpenParcelBox is an international open-source project with a strong expected early community in Germany.

The project therefore uses a bilingual community model:

- English is the primary technical project language.
- German and English are both welcome in community discussion.

## Technical project language

The following should be written in English where possible:

- source code
- APIs
- protocol names
- file and directory names
- commit messages
- architecture decision records
- specifications
- release notes
- security advisories
- normative project documentation

Reason:

English keeps the project accessible for international contributors, standards work, manufacturers, firmware developers, carriers and open-source communities.

## Community languages

Issues, discussions and community posts may be written in English or German.

German contributions are explicitly welcome, especially for:

- DHL parcel box retrofit reports
- Home Assistant and HomeMatic experience
- German delivery workflows
- German policy/regulatory research
- local installation examples
- practical maker feedback

Maintainers may translate, summarize or restate German discussions in English when the topic affects:

- architecture
- firmware behavior
- security
- privacy
- standards interpretation
- public roadmap decisions
- cross-language contributor coordination

## Website languages

The public website should be available at least in:

- English: `/`
- German: `/de/`

English is the default international landing page. German pages should make it easy for the early German-speaking maker and retrofit community to join.

## Discussion language convention

Discussion titles should ideally make the language obvious when helpful:

- `[DE] Umrüstung DHL Paketkasten mit Wiegand-Keypad`
- `[EN] Standalone ESP firmware model`

This is a convention, not a hard rule.

## Translation quality

The project does not require perfect translation before useful ideas can be shared.

Useful technical content is more important than polished language. Maintainers can help translate or summarize important points.
