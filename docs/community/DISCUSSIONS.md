# GitHub Discussions Structure

OpenParcelBox should use GitHub Discussions as the public community forum.

The project is technical-first and international, but German discussion is explicitly welcome.

## Suggested categories

| Category | Purpose | Language |
|---|---|---|
| Announcements / Ankündigungen | Maintainer updates, releases, roadmap notes | English or bilingual |
| General / Allgemein | Broad project questions and orientation | English or German |
| Deutschsprachige Community | German-language discussion, retrofit reports, local questions | German |
| Ideas / Ideen | Early ideas before they become issues | English or German |
| Retrofit Reports / Umbau-Berichte | Real parcel boxes, photos, lock conversions, cable routing | English or German |
| Hardware | Core, locks, sensors, power, solar, access modules | English preferred, German welcome |
| Firmware | ESP firmware, local UI, storage, OTA, access validation | English preferred |
| Home Assistant / HomeMatic | Smart-home integration and 868 MHz/HomeMatic-related experience | English or German |
| Standards & Policy | CEN/TS 17457, CEN/TS 16819, carrier interoperability, regulation | English preferred, German welcome |
| Show and Tell | Builds, prototypes, sketches, demos | English or German |
| Q&A / Hilfe | Support-style questions | English or German |

## Issue vs discussion rule

Use Discussions for:

- open questions
- ideas
- brainstorming
- retrofit reports
- community input
- photos and component findings

Use Issues for:

- concrete tasks
- bugs
- specifications to write
- research tasks
- design decisions with acceptance criteria
- implementation work

## Language handling

German discussion is not second-class.

When a German discussion produces a project-relevant decision, maintainers should summarize the outcome in English in the linked issue, ADR, specification or roadmap document.

## Suggested pinned discussion

Title:

`Welcome / Willkommen: how to participate in OpenParcelBox`

Suggested content:

- OpenParcelBox is bilingual: English and German are welcome.
- Technical specs and code are maintained in English.
- German retrofit reports and practical experience are especially valuable.
- Use Issues for concrete work and Discussions for open questions.
- Cloud and Home Assistant are optional. The local device must keep working.
