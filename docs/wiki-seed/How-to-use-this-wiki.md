# How to use this wiki

The wiki is an entry point, not the project archive.

## What belongs here

- short roadmap overview
- "where do I start?" pages
- FAQ-style explanations
- links to current issues, milestones and discussions
- lightweight community orientation

## What belongs in the specs repository

- architecture decisions
- security assumptions
- standards baseline
- hardware profiles
- access-control model
- firmware requirements
- compatibility and manufacturer rules
- normative project wording
- anything that should be reviewed through pull requests

## Rule of thumb

If a page defines how OpenParcelBox should work, it belongs in `OpenParcelBox/specs`.

If a page helps people find the right place, it can live in the wiki.
