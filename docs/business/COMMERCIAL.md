# Commercial Use and Business Model

OpenParcelBox is open at its core and designed for professional collaboration.

The project may offer commercial hardware, cloud services, consulting, custom integrations, support, certification and enterprise features without giving up the open community foundation.

## Commercial principles

Paid services should cover real value such as:

- operation
- hosting
- support
- integration
- certification
- liability
- security
- convenience
- maintenance
- professional deployment

Paid services should not be based on artificial lock-in or deliberately broken community features.

## Possible commercial offerings

OpenParcelBox may offer:

- plug-and-play hardware
- retrofit kits
- OpenParcelBox Bridge devices
- OpenParcelBox Lock devices
- OpenParcelBox Locker products
- OpenParcelBox Cloud Hosted / Managed Cloud
- OpenParcelBox Cloud Enterprise
- consulting
- custom plugin development
- carrier/API integrations
- hardware compatibility work
- certification
- support and maintenance contracts
- white label solutions
- partner programs
- enterprise locker deployments
- managed updates
- security reviews
- deployment support

## Consulting and custom integrations

Companies may hire OpenParcelBox to design or implement:

- carrier integrations
- parcel box integrations
- lock hardware integrations
- Home Assistant integrations
- MQTT integrations
- cloud connectors
- plugin systems
- enterprise dashboards
- API bridges
- house-management integrations
- public locker workflows
- security concepts
- prototype hardware

## Open source and commercial use

Commercial use of open components is allowed under the applicable license terms.

However, commercial use of the OpenParcelBox name, logo, certification marks, hosted service names or official compatibility claims is governed separately by the trademark and brand policies.

## Certification and compatibility

OpenParcelBox may offer certification or compatibility programs such as:

- OpenParcelBox Certified
- OpenParcelBox Compatible
- OpenParcelBox Secure Bridge
- OpenParcelBox Enterprise Ready
- Powered by OpenParcelBox

Use of these names or marks requires written permission and may require testing, review, certification or commercial agreement.

## Cloud and enterprise services

Official hosted cloud, managed cloud and enterprise offerings may be provided under separate commercial terms.

These services may include:

- push notifications
- secure remote access
- backups
- managed updates
- carrier integrations
- trust registry
- public locker directory
- identity services
- device claim services
- enterprise support
- SLA
- white label
- multi-tenant locker systems

## Community benefit principle

Every major commercial direction should preserve or create meaningful community benefit, such as:

- open specifications
- self-hosting support
- documented APIs
- local operation
- reference implementations
- compatibility tools
- public registries
- reusable SDKs
- improved documentation
- security hardening

## No automatic partnership

Using OpenParcelBox code under an open source license does not create an official partnership, certification, endorsement or right to use OpenParcelBox marks.
