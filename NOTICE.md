# Notice

OpenParcelBox was initiated in 2026 by Jan Elsner / OpenParcelBox Project as an open, local-first and self-hostable project for smart parcel boxes, retrofit locks, secure bridge firmware, self-hosted access control, optional cloud services and professional integrations.

The official project website is:

https://openparcelbox.org

OpenParcelBox is intended to provide an open foundation for:

- smart parcel boxes
- retrofit parcel locks
- bridge firmware
- MQTT and Home Assistant integration
- self-hosted backend services
- optional hosted cloud services
- plugin systems
- public locker infrastructure
- commercial integrations
- future locker and enterprise systems
