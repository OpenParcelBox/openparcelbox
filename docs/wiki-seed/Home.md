## Project idea

OpenParcelBox is an open ecosystem for smart parcel delivery infrastructure, retrofit parcel boxes, open locks and local-first access control.

The goal is not one closed parcel box. The goal is a set of open, repairable and interoperable building blocks for parcel reception at homes, apartment buildings, neighborhoods and civic locations.

## Current focus

The first concrete milestone is a standalone retrofit for existing DHL parcel boxes:

- keep existing boxes useful
- replace the closed control layer
- support local access through keypad, NFC and prepared fingerprint paths
- log openings locally
- avoid mandatory cloud, mandatory Home Assistant or single-carrier lock-in
- start with ready-made low-voltage modules before deriving a later reference board
